Abby AHX Amiga

Hello again!

This time, I'm bringing you a native Windows-only version of Avix AHX Amiga, based on Dexter Pinky's AHX tracker.
If you would like to port it to other operating systems, feel free to do so using the source code available here in the repository.

About the Project

AHX is a very old tracker, quite similar in concept to some of the most well-known music trackers. This project was inspired by the tracker community, and I'd especially like to thank 16-bit for inspiring me through his projects. That motivation encouraged me to bring this version to life, keeping it as close and faithful to the original as possible.

Features and Improvements

Here are some of the features and additions included in this version:
Amiga 500 Emulation: Emulates the 1500 LPF 3.3 filter, recreating the characteristic sound of the Amiga 500.
Custom Themes: Create and customize your own visual themes using the available filter and theme options.
Help Menu: An integrated menu to help you learn how to navigate the tracker and understand its keyboard shortcuts.
Original Effects and Waveforms: Includes the original tracker effects and waveforms.

<img width="962" height="800" alt="main3" src="https://github.com/user-attachments/assets/6c5caa16-0fa6-4963-8c29-84cdb7f754f5" />

Sample Loading: Load samples directly into the tracker by emulating a floppy disk, or import them externally.
Tracker Format Support: Open classic tracker music formats and export your compositions in high quality.
Four-Channel Architecture: A classic four-channel tracker with virtually endless possibilities through its sequences and patterns.
Mouse Emulation: Three different mouse interaction modes, including a realistic emulation of the original experience.
Editing Operations: Clone, copy, paste, and delete elements directly within the tracker.
Sample Editor: An integrated sample editing environment inspired by the classic sample editors found in ProTracker and other trackers.

Performance Editor: Open the Performance Editor to access your samples, edit them, create new samples from existing ones, and perform various sample manipulation operations.
Live Sample Playback: Play and preview your samples in real time.

Important: First-Time Setup

There is one small detail worth mentioning when launching the tracker for the first time.
When you start the application, navigate to INS and look for the Test Mode option. It will be enabled by default. Simply disable it, and the tracker will start operating normally, allowing you to create and play your sequences without any problems.
I intentionally kept this behavior as part of the emulation experience after discovering an issue in the original code. It also adds a small touch of authenticity to the quirks and peculiarities of the classic tracker environment.

Final Thoughts

This project was genuinely fun to develop, although certain aspects were quite challenging.
Despite being a four-channel tracker, AHX offers an incredible amount of creative freedom. My goal was to preserve the original experience while bringing additional functionality and a more accessible environment to modern Windows systems.
I hope you enjoy using it as much as I enjoyed working on it.
As always, the source code is available for you to study, modify, experiment with, and use as a foundation for your own improved versions or ports to other platforms.
Feel free to explore, learn, and build upon it.

Enjoy making music!
